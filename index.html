跨裝置同步（JSONBin.io）

到 jsonbin.io 註冊 → 建立一個 Private Bin（內容填 {}）→ 把 Bin ID 和 X-Master-Key 填在下面。 電腦和手機填同一組就會共用資料；留空則只存這台裝置。

匯出備份

按下面按鈕，會把句庫、模考記錄、句型庫全部打包成一份文字，複製起來存到你自己的地方（Google Doc / Notes 都可以）。之後如果這個工具的資料不見了，把這份文字貼到下面「還原」欄位就能整份復原。

還原備份

把之前存起來的備份文字貼到下面，按「還原」會覆蓋目前工具裡的所有資料，請先確認貼對內容。
